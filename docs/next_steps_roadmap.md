### 一条反直觉的建议：别把主要精力放在 L1

L1（S-1/S-2 融合表层土壤水）是**最拥挤**的赛道，审稿人对"又一个融合产品"天然疲劳。
本课题的护城河在 **L4（形变 → 储变量 → 根区水闭合）**，这是别人做不了的。

所以资源分配上：**L1 做到"够用"即可（ubRMSE ≤ 0.04 就停手，不去卷 0.03），
把算力与人力压到 L2 和 L4。**

## 5. 关键判据与退路

| 检查点 | 判据 | 不达标怎么办 |
|---|---|---|
| **P0-a 相干性** | 干旱区夏季 γ > 0.4 | 转 L 波段（NISAR / LT-1）或转湿地 |
| **P0-b 季节振幅** | SNR ≥ 3 | 改张掖/黑河中游；科学问题改为"绿洲灌溉—地下水—形变" |
| **配准** | 同名点残差 < 0.5 像元 | 回到配准，不要往下走 |
| **L1 精度** | ubRMSE ≤ 0.04、anomaly R ≥ 0.6 | 检查干湿动态范围是否 ≥ 3 dB；不足则该区不可反演 |
| **L1 vs L2** | 差 < 0.06 m³/m³ | 查 C4 是否跳了截距项；比较时看 **RMSE 与 bias**，别看 ubRMSE |
| **空间块 CV vs 随机 CV** | R² 之差若 > 0.15 说明泄漏 | 两个都报，别只报随机 CV |
| **闭合残差** | ≤ 0.15·P | 灌区必须补灌溉与抽水记录、渠系渗漏与回归水 |
