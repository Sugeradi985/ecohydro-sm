# 实验执行手册：数据准备、处理步骤与可靠性判据

**原则：先用合成数据闭环，再上真实数据。**
仓库已提供 `--selftest`（`make selftest`），能在没有任何真实数据的情况下验证算法链路。
先把它跑通，再下载数据——否则很容易在几十 GB 数据上遇到本可以提前发现的问题。

---

## 0. 实验规模的最小建议

| 维度 | 最小可行 | 推荐 |
|---|---|---|
| 时间跨度 | 2 年（覆盖 2 个完整季节循环） | 3–5 年（L4 需要长时序分离趋势与季节项） |
| 空间范围 | 1 景 Sentinel-1（约 250 km 幅宽） | 民勤盆地 + 一个对照区 |
| S-1 轨道 | 1 条（升或降） | 升 + 降各一条（可做交叉检验） |
| 地面站点 | **3–5 个 TDR 剖面站** | 8–15 个，覆盖不同覆被与土壤质地 |
| 水位井 | 3 口（月频） | 10 口以上 + 分层标 |

L4（形变→储变量）对时序长度最敏感：**少于 3 年时，趋势项与季节项无法可靠分离**，
S_ke 标定会有很大不确定性。

## 1. 数据清单

### 1.1 必需

| 数据 | 规格 | 用途 | 获取 |
|---|---|---|---|
| **Sentinel-1 RTC γ⁰** | IW, VV+VH, 30 m, 含入射角与 DEM 层 | L1 主输入 | ASF HyP3 `RTC_GAMMA`（`radiometry=gamma0`） |
| **Sentinel-2 L2A** | B4/B8A/B11 + SCL | NDVI / NDMI / FVC / VWC、云掩膜 | GEE 或 Copernicus Data Space |
| **ERA5-Land** | 0.1°，逐时 | 降水、2 m 气温、土壤温度、参考土壤水；掩膜与三重配置 | CDS |
| **地面土壤水观测** | 0–5/10/20/40/80 cm，逐时或逐日 | 残差校正 + 验证 | **自建，最可能缺失的一项** |
| **土壤质地** | 砂/粉/黏、孔隙度、田间持水量 | 残差校正协变量 | SoilGrids 2.0 |
| **Sentinel-1 SLC** | IW VV，连续 ≥ 3 年，单轨 | L2 相干性、L4 形变 | ASF |
| **地下水位** | 月频或旬频 | S_ke / S_y 标定 | 地方水文部门 |

### 1.2 强烈建议（缺了会显著削弱结论）

| 数据 | 用途 |
|---|---|
| SMAP L3 或 ESA CCI SM | 三重配置、产品基准 |
| GLEAM / PML_V2 ET | 水量平衡闭合 |
| **灌溉与抽水记录** | 民勤这类灌区，**没有它水量平衡闭合基本不成立** |
| 地上生物量 / LAI 样方 | 标定 WCM 的 A/B/E 与 VWC–NDVI 关系 |

### 1.3 可选

NISAR GUNW / SME2（L 波段，用于 VWC 高区补位）、GRACE/GRACE-FO（独立约束 ΔS）、
国产 LT-1（L 波段 4 天重访，需申请公益数据）。

> **最容易被低估的是地面观测。** 西北地区 ISMN 站点稀少，
> 没有自建站点就只能靠三重配置做无真值评估，而 L3（根区土壤水）将**完全无法验证**。
> 这一步不能省，也不能指望用公开数据替代。

## 2. 处理步骤与可靠性判据

每一阶段都给出**可计算的判据**。判据不满足就不要往下走——
后续阶段的误差会被放大，而不是被平均掉。

### 阶段 A｜数据准备与配准

| 步骤 | 做什么 | 可靠性判据 |
|---|---|---|
| A1 | 定义时空范围与投影（UTM 分带） | 研究区跨带时必须选单一投影并说明变形 |
| A2 | 下载 S-1 RTC（HyP3） | 有效景数 ≥ 时间跨度 × 预期重访数的 80%；入射角覆盖 30–45° |
| A3 | 下载 S-2 L2A 与 SCL | 晴空有效率：干旱区 > 70%，季风区可能仅 40–60% |
| A4 | 统一网格与配准 | **同名点残差 < 0.5 像元**；用互相关或固定地物检验 |
| A5 | 时间匹配（S-1 与 S-2 过境） | 记录"距最近有效光学观测天数"，作为显式特征 |

**失败处理**：A3 有效率过低（< 40%）→ 只能依赖 ERA5-Land 先验填补，
且必须在论文里声明光学时相缺口；不要用月最大值合成掩盖。

### 阶段 B｜L1 表层土壤水

| 步骤 | 做什么 | 可靠性判据 |
|---|---|---|
| B1 | 掩膜（云/冻融/降水/入射角） | 掩膜后有效样本率；冻融期必须被完整剔除（用土壤温度而非气温复核） |
| B2 | 标定 WCM 的 A/B/E（需生物量样方） | 正演 σ⁰ 与实测 σ⁰ 的 RMSE < 1.5 dB |
| B3 | 生成合成库并训练反演器 | **合成库自洽 ubRMSE < 0.05 m³/m³** |
| B4 | 实测残差二级校正 | 校正后 \|bias\| < 0.02 m³/m³；站点数 < 20 时只做全局 bias |
| B5 | 生产并按 `aggregate_factor` 聚合 | 标称分辨率 = 实际聚合后分辨率（不可虚标） |
| B6 | 升降轨分别反演再融合 | **升/降轨同期结果差 < 0.05 m³/m³**，超出说明入射角或定标有问题 |

**L1 的验收判据（与站点比）**

| 指标 | 目标 | 说明 |
|---|---|---|
| ubRMSE | ≤ 0.04 m³/m³ | 按 VWC 分层报告，不报全样本单一值 |
| bias | \|bias\| ≤ 0.02 | 可校正的系统偏差 |
| anomaly R | ≥ 0.6 | **生态水文应用真正关心的量** |
| 空间块 CV vs 随机 CV 之差 | 若 > 0.15（R²）说明泄漏严重 | 必须两个都报 |
| 干湿动态范围 | ≥ 3 dB | 低于此值判为不可反演 |

### 阶段 C｜L2 相干性支路

| 步骤 | 做什么 | 可靠性判据 |
|---|---|---|
| C1 | 干涉对筛选（≤ 12 天 / ≤ 150 m） | 干涉对数量 ≥ 30；基线分布集中 |
| C2 | 提取相干性（大窗口多视 ~200 m） | **干旱区平均 γ > 0.4**；低于 0.15 的像元不参与反演 |
| C3 | 构建结构变化指数 ΔV（S-2 FVC） | ΔV 与物候同步（抽穗/收获期应出现峰值） |
| C4 | 标定 k_sm、k_v（含截距） | 拟合 R² ≥ 0.5；k_sm、k_v 均为正 |
| C5 | 闭合相位残差质控 | 残差 std > 阈值（默认 0.8 rad）的像元标记不可用 |
| C6 | 反演并与 L1 交叉 | **L1 与 L2 的差 < 0.06 m³/m³**（二者观测机制独立） |

**关键警示**：C4 若跳过截距项，k_sm 会低估约 20%（仓库修 bug 前的实测：2.5→1.95）。
另外，比较"是否加入结构去混"时必须看 **RMSE 和 bias**，看 ubRMSE 会得出错误结论——
结构去混改善的主要是系统偏差，ubRMSE 会先把偏差剔除掉。

### 阶段 D｜L4 形变 → 储变量

| 步骤 | 做什么 | 可靠性判据 |
|---|---|---|
| D1 | **P0 预检**（先做，30 天） | **季节振幅 SNR ≥ 3**；不满足就换研究区或放弃 L4 |
| D2 | 时间序列分解（谐波 + 趋势） | 季节项 + 趋势项 + 截距 + 残差 = 原始形变（闭合检验） |
| D3 | 滞后校正（时滞互相关） | 校正后形变—水位相关 **R ≥ 0.6**（校正前应显著更低） |
| D4 | 标定 S_ke | **符号为正**，且落在文献区间内（华北 2×10⁻⁴–2.1×10⁻²） |
| D5 | 转储变量（路径 A 或 B） | 井稀疏时走路径 B（形变仅加密水位场） |
| D6 | S_y 敏感性分析 | **必须给区间**；与抽水量或 GRACE 独立估算的差异 < 30% |

**D1 是整条链路的生死线。** 民勤盆地目前还没验证形变可探测性，
在投入大量算力之前必须先把这一步做完。

### 阶段 E｜L3 闭合 → 根区土壤水

| 步骤 | 做什么 | 可靠性判据 |
|---|---|---|
| E1 | 统一量纲（全部转 mm） | P、ET、R、ΔS 单位一致 |
| E2 | 计算 ΔS_vad = P − ET − R − ΔS_gw | 闭合残差理论上为 0 |
| E3 | 沿深度分配得根区 SM | 值域 0–0.6 m³/m³；浅层变幅应大于深层 |
| E4 | 与实测剖面比较 | **闭合残差 \|P−ET−R−ΔSgw−ΔSvad\| ≤ 0.15·P** |

**失败处理**：灌区必须把渠系渗漏与灌溉回归水单独计入，否则闭合残差会系统性偏大。

## 3. 不依赖真值的可靠性自检

地面站点稀少时，用这五类交叉检验兜底：

1. **时间连续性**：土壤水不应逐日跳变。相邻时相差超过 0.15 m³/m³ 且无降水事件 → 可疑。
2. **事件响应**：降水后 1–3 天上升，随后指数衰减。响应幅度与时滞不合理说明模型学错了东西。
3. **升降轨一致性**：同一时期两条轨道的结果应接近（见 B6）。
4. **多产品交叉**：L1、L2、ERA5-Land、SMAP 四者两两比较，异常者单独排查。
5. **三重配置**：无真值下估计各自随机误差——但注意它**无法验证误差独立性**，
   若 SMAP 与 ERA5-Land 都依赖陆面模式，需引入第四套数据或站点。

## 4. 常见失败模式对照表

| 症状 | 最可能的原因 | 检查项 |
|---|---|---|
| R² 高达 0.8，换区就崩 | 随机 CV 的空间泄漏 | 改空间块 CV，对比两者差距 |
| 生长季误差突然变大 | 植被结构去相干未分离 | 启用 L2 结构去混，看 bias 是否下降 |
| 把总形变当储变量，量级离谱 | 未分离永久压实 | 先做谐波+趋势分解 |
| ΔS 与抽水量差一个数量级 | 直接把 Δd 当 ΔS | 用 S_y/S_ke 转换并给区间 |
| 产品"10 m"但细节模糊 | 标称与实际聚合不一致 | 标称分辨率 = 实际聚合后分辨率 |
| 冻融期结果完全不可用 | 只用了气温掩膜 | 用土壤温度层复核 |
| 闭合残差系统性偏大 | 漏了灌溉回归水 | 补灌溉与抽水记录 |

## 5. 执行顺序检查单

```
[ ] 0. make selftest —— 合成数据闭环跑通
[ ] 1. 下载 S-1 RTC（HyP3，radiometry=gamma0）
[ ] 2. 下载 S-2 L2A + SCL
[ ] 3. 下载 ERA5-Land、SoilGrids
[ ] 4. 站点数据整理（TDR 剖面 + 水位井）
[ ] 5. 配准检查：同名点残差 < 0.5 像元
      ↓ 判据不通过则回到第 5 步
[ ] 6. L1：掩膜 → 标定 → 训练 → 残差校正 → 生产
      ↓ ubRMSE ≤ 0.04 才继续
[ ] 7. L2：干涉对 → 相干性 → 标定 → 闭合相位质控 → 交叉
      ↓ 与 L1 差 < 0.06 才继续
[ ] 8. L4：P0 预检（SNR ≥ 3）→ 分解 → 滞后 → S_ke → ΔS
      ↓ 与抽水量/GRACE 差 < 30% 才继续
[ ] 9. L3：闭合 → 根区分配
      ↓ 闭合残差 ≤ 0.15·P
[ ] 10. 验证：空间块 CV + 留一站出 + 三重配置 + 分层报告
```
